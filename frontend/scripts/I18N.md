# i18n Scripts

Scripts for managing and maintaining translation files.

## Scripts

### `i18n-reverse-map.ts`

Generates a reverse mapping of French translation values to their keys.

```bash
npx tsx scripts/i18n-reverse-map.ts
```

**Output:** JSON object where keys are French values and values are arrays of translation keys.

```json
{
  "Supprimer": ["common:actions.delete", "common:buttons.delete"],
  "Modifier": ["common:actions.edit", "common:actions.edit"]
}
```

**Use cases:**
- Find duplicate translations across namespaces
- Identify consolidation opportunities
- Audit translation consistency

### `i18n-consolidation-report.ts`

Analyzes duplicates and suggests which translations should be consolidated into `common.json`.

```bash
npx tsx scripts/i18n-consolidation-report.ts
```

**Output:** JSON report with summary and categorized consolidation suggestions.

### `i18n-migrate.ts`

Migrates locale files and updates source code to use consolidated keys.

```bash
# Dry run (preview changes)
npx tsx scripts/i18n-migrate.ts --dry-run

# Apply changes
npx tsx scripts/i18n-migrate.ts
```

**What it does:**
1. Adds consolidated keys to `common.json` (both en and fr)
2. Removes migrated keys from domain-specific locale files
3. Updates source files to use `tCommon()` instead of domain-specific translations
4. Adds `tCommon` hook where needed

## Consolidation Rules

Translations are consolidated to `common.json` when:

| Category | Example Keys | Target |
|----------|-------------|--------|
| Status | `*.status.DRAFT/PUBLISHED/CANCELLED` | `common:status.*` |
| Actions | `*.actions.delete/edit/publish/unpublish` | `common:actions.*` |
| Form labels | `*.descriptionLabel`, `*.statusLabel` | `common:form.*` |

## After Migration

Always verify changes:

```bash
pnpm i18n:lint      # Check for hardcoded strings
pnpm exec tsc --noEmit  # TypeScript check
```

## Adding New Consolidations

Edit `CONSOLIDATIONS` map in `i18n-migrate.ts`:

```typescript
const CONSOLIDATIONS: Record<string, string> = {
  'namespace:old.key': 'common:new.key',
}
```

Then add the new keys to `NEW_COMMON_KEYS_FR` and `NEW_COMMON_KEYS_EN`.
